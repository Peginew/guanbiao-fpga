本目录收录本项目编写的训练、ROI转换、整数推理、几何匹配、标定、方案比较及既有评价记录。原始源码与权重按字节复制，并逐文件核对SHA256；本次没有训练、编译或重新运行C/H评价。

`frozen_math/7b58`与`frozen_math/793d`提供两版固件原样的算术实现和训练权重头文件，`math_identity.json`记录逐文件SHA一致性。793d是异常访问恢复修复；这些模型数学文件和权重与7b58保持一致，不将修复解释为重训。

## 目录与依赖

`algorithm_work/`保留原任务目录结构，便于读取脚本中的相对导入。数据图片由仓库根的数据集部分提供，本目录不重复复制原图。

Python训练和导出主要依赖Python 3.12、NumPy、PyTorch、OpenCV；部分可视化脚本还依赖Pillow/Matplotlib。具体训练软件版本以各run的原始`config.json`、`training_receipt.json`等记录为准，不把本次整理环境冒充原训练环境。请通过这些项目的正规发行渠道安装依赖，本目录未打包第三方运行库或Python环境。

完整MCU构建还需要官方安路FD/RISC-V工具链及其SDK。官方启动/异常对象和SDK属于外部依赖，未作为本项目自有算法源码复制。这里的纯C数学代码与完整固件构建是不同层次，不能把纯C文件存在称为可直接烧录。

部分历史脚本/冻结manifest保留了原工作站绝对路径和SHA断言。跨电脑复现须配置实际数据与工具链路径，并保留原始记录；当前是按原字节公开源码，不宣称未经路径配置即可一键运行。`dependency_report.json`列出静态扫描发现的其它任务目录引用，未包含的依赖标为缺口。

## 结果与验收边界

最终冻结C组只评价一次：59图中56有表、3负例；同整数环参考19条输出，六点融合31条输出，新增12、撤回0，旧19条逐值保持；31条MAE约0.16847psi，仍25张有表图拒读，负例0/3输出。0.5psi只是描述性分档，不是用户确认的容差。输入是人工框HDMI128灰度代理ROI，不是自动CSI输入板验。

H属于更早dd8a候选的历史一次评价：16/56输出，其中14在描述性0.5psi内，最大误差2.09375psi。H未重新评分或用于后续调参；不可把该H结果冒充7b58最终C评价，也不可把G多轮开发结果当独立测试。完整数字见既有JSON回执。

新87da配套训练固件后来已真实上板并完成存储/冷启动相关验证；自然任务仍有取消，未完成稳定轴针和压力读数验收。793d受控异常恢复通过不等于读表成功。本目录不改变板卡状态，不包含任何自动设备操作授权。
