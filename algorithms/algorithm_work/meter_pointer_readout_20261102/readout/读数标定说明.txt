观表 · 本轮PC离线读数转换说明

这条路径已经把候选的预测针角转换为bar数字，但尚未部署到MCU或FPGA，也不代表板上读数验收。

实际输入与职责
1. 模型输入仍为原生HDMI图片生成的128×128表盘ROI。这里的盘面框是手工标注代理，不能冒称自动定位已经端到端通过。
2. readout读取每图模型预测的图像针角、证据许可及源图片ID。程序不使用该图真实压力、真实针角或真实轴针点来决定输出。
3. 每图相对旋转来自原图像素及盘面框：SIFT静态印刷特征＋RANSAC单应性，以训练D002的固定人工印刷区域为参考。查询图不读取真实轴心、细针点或psi。中心、背景、外金属圈和已知OSD区域不作特征；参考针扇区在一次设置时固定排除。
4. 相对旋转不是绝对正立或真实yaw/pitch。静态印刷证据不足或局部形变过大时拒读，不把未知角设为零。

标定性质与来源
采用D/E/F中72张具有合格直接视觉轴针标签、正面场景与静态配准证据的照片，按用户psi设置建立14个压力档的经验角度—压力标定。
标签点来自图片可见机械结构，未由压力反推；用户psi只用于后续标定拟合。
标定是经验线性拟合，不是OCR读取刻度数字后直接确定量程。面盘可见内圈bar、外圈psi，但本轮没有把印刷数字识别冒充已完成。
公式：bar = 0.005019222203317465 × theta_ref − 0.6250605302201702
其中theta_ref为模型图像角减静态印刷相对转角，再按训练确定的角度分支展开。
训练经验支持约2.5～12psi，即0.17237～0.82737bar；严格不外推。
该范围仅属于本PC候选，不修改现有板上0～0.51bar TEST标定。
训练拟合MAE0.01030bar、最大0.03262bar。用户压力参考精度未知，这些不是仪器计量精度认证。

验证与错误接受
G只用于评估，未拟合标定参数。预先采用0.05bar工程误差目标。
run002真CNN：56张有表图中输出16张，8张在0.05bar内，8张错误接受；输出MAE0.15633bar，3张无表反例均未输出。该结果不能验收。
另一个oracle_visual_angle_diagnostic明确使用G直接可见标签针角，仅分解标定/姿态的潜在误差：输出39张、MAE0.01363bar。它不是CNN效果，也不能作为部署结果。
所有候选统一使用同一冻结标定、静态姿态与误差阈值，不能按G真压力挑选TopK方向。

运行方式
python readout_adapter.py calibrate
python readout_adapter.py evaluate --predictions ../keypoint_aux/run_A/validation_evaluation.json --out candidate_A_readout.json
root候选B也可传JSONL：每条包含id、angle_deg_image、valid、score及model_name（score可选）。
脚本也兼容run002格式JSON中的rows、angle_deg和evidence_accepted。

边界
输出数字仍缺车辆停车、完整同源观察与实际硬件读数许可等整机条件。
原图含OSD/ISP影响，不能宣称与CSI捕获的ROI字节相同。
本轮没有打开H或A/B/C，没有训练器以外的模型新增训练，没有改写原图、坐标、固件、位流或板卡。
