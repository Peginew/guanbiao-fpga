# 单一D025模板的ROI128静态印刷点候选

`predictions.jsonl`为本轮唯一冻结评价输出：D/E/F训练输入164条、G开发输入59条。每行提供六身份的accepted、normalized_xy/roi_xy、候选位置、NCC分数、次峰margin与证据足/不足。分数不是正确概率，accepted也不证明物理未遮挡。

输入只有128×128 U8灰度、原1202参数网络的预测轴心和定位半径；不依赖已知针方向，不访问query原生图、人工静态点、人工可见性或psi。六身份为外圈5/10/15完整印字与上篮球、中足球、下条纹球标识。

唯一模板来自清楚的TRAIN D025，实际先转为相同128ROI，再做9×9局部对比及C64/r48归一化。D002的两logo受针/配重污染，不建模板；仅D002与D025共同清楚的外5/10/15/下标识四点作训练内相似对齐。D002→D025角偏置为−2.3834504963646026°；query的D025拟合角再加此偏置得到D002相对角，符号由root几何接口统一处理。

冻结旋转bank为−24到28步长4°，共14项；每项同时旋转patch纹理与相对C64的预期点，位置窗为±20像素。文字17×17全mask；三logo13×13固定r5圆形bodymask（81点）排除TRAIN邻近针的角部上下文。严格同mask计算模板均值/能量及query和/平方和，通过三次TM_CCORR实现零均值NCC；非简单乘mask后调用未mask归一化。

NCC≥0.68且排除6像素同一空间峰后的margin≥0.06，才输出足够证据；低方差unknown。模板mask内std≥8。所有范围、模板、门及数学均在G预测前冻结；不使用G手标删错点或缩小搜索窗。

`preflight.json`只包含D025自匹配、常量未知、人工遮足球和合成±24°符号检查。严格masked公式另与60个逐窗FP64计算核对，最大差2.74e−8。自匹配六点足够、常量全unknown、该训练遮挡点unknown；这些不是独立识别准确率。早期未mask原型保留在`history/pre_bodymask/`，它从未运行G，不是失败G版本。

主负责人负责≥3独立身份的几何consensus、相似变换与psi评价，并在旧参考accepted时逐字保留旧结果。本定位模块没有自行修改旧CNN、旧环、旧标定或READ许可；113个G点证据足不等于113个正确点，更不等于增加了读数。

成本仅PC实现：模板bank76944B＋mask5496B；显式图、score、winner、far及两张I64网格合计至少491520B，另有相关/平方/除法临时量，实际峰值未测。最大单相关等价乘积32335716、三相关等价97007148/ROI，未计完整OpenCV内部算子及sqrt开销。PC均8.92ms不代表MCU周期；没有整数NCC、整应用TCM链接或上板声明。

最终源/配置/输入绑定见`setup.json`与`completion.json`。本轮没有神经网络训练、H/ABC输入、MCU/RTL/OSD/Flash或车辆操作。不要改冻结配置重跑G；效果不佳应保留失败证据。
