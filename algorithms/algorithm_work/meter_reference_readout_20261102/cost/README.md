# StaticRoll候选成本：仅合成前向及现存链接证据

`account_static_roll.py`只导入网络定义、用全零合成输入执行torch hooks，不加载训练/验证图像，不训练、不编译、不操作设备。逐层记录见 `逐层成本.csv`，完整来源和限制见 `static_roll_cost.json`。

实际定义为6226参数，名义634624 MAC，去padding617560 MAC；尚未整数化的规划存储为6136个INT8权重＋90个S32偏置＝6496B。最大单层输出为16384个元素。该数不是总运行内存，也不是实际MCU周期。

9×9均值的行式整数原型在3个合成输入共49152像素上逐值等于当前OpenCV CV16S/replicate结果。规划9行U8源缓存1152B＋U16列和256B，共1408B；首层5行INT8卷积缓存另640B。此原型没有实现完整量化、环掩码、反量化或MCU集成。

已直接读取当前fea819固件ELF及已签map：TCM49152B；两块16KiB激活数组和640B行缓存已占用；BSS结束0800B284，固定2KiB栈开始0800B800，真实静态间隙1404B。仅把新网络6496B整数权重附加到原TCM，就至少短5092B，尚未计新增代码、极坐标针网及其他表。当前Flash LMA内容会复制到TCM，并不自动节省TCM。

原hub1202＋polar1009＋StaticRoll6226共8437参数，只是网络算术合计；新极坐标、姿态和psi链尚未整体C链接。顺序复用旧32KiB scratch、从同一owned ROI重新取样、权重放Flash或删除被替代支路均须真实生命周期与链接验证，不能当作已节省。

该StaticRoll唯一训练轮的效果已由主负责人判定FAIL，不采用；本成本记录仅保留失败候选证据。后续优先对已有收益的多参考环B进行整数/C移植，而非继续训练或部署该候选。
